# KPopTournamentData

"Pick Your Bias" 앱(iOS)이 사용하는 K-Pop 아이돌/그룹 팩트 데이터(이름/그룹/포지션/세대/데뷔년/테마컬러)의 CDN 배포용 저장소입니다.

- 사진·로고·공식 콘텐츠 없음 — 공개된 팩트 데이터만 포함합니다.
- 원천: [kpopnet.json](https://github.com/kpopnet/kpopnet.json)(CC0), [Wikidata](https://www.wikidata.org/)(CC0)
- 앱은 이 저장소의 `dataset.json`을 [jsDelivr](https://www.jsdelivr.com/)를 통해 주기적으로 확인해 콘텐츠만 갱신합니다(앱 동작/기능은 변경하지 않음).
- `dataset.json`은 자동 생성 산출물입니다. 손으로 편집하지 마세요.
